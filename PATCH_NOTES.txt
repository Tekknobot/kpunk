ZPUNK - PROJECT RESTORE / HELM SOUND FIX
========================================
Merge the Assets folder into your project's Assets folder.
Overwrite only these 4 files. Retain existing .meta files.

CAUSE: Legacy project saves contain a full copy of UI sound-bus parameters.
When the preset is selected on project load, those cached (possibly stale)
UI values were written back into Helm after the .helm file loaded. That can
turn distortion on, alter oscillators or filters, or make the sound incorrect.
Changing to the next preset bypasses the project override and restores the
correct native patch, explaining why patch navigation seems to fix it.

PATCH:
* Legacy saves: restored project sound is the actual .helm preset. Ignore
  old Synth/Pad UI cached parameters for native sound; retain project content,
  presets, track arrangement and mixer/non-synth bus data.
* New saves: persist the actual native Helm settings (not the UI cache).
  Restore this sound snapshot only after the matching preset finishes loading.
* Sync native sound back into UI after restore.
* Restore each channel's master volume only after its preset loads.
* Pads: use real native FX on/off controls, never zero the dry/wet mix as a
  substitute for an off switch.
* Remove a single zero-byte SFX .helm from the preset index (source file intact).
* Log successful patch restores for diagnosis in Unity Console/device logs.

BACKWARD COMPATIBILITY:
Older projects remain readable and retain their musical content. Their saved
Synth/Pad preset is now treated as authoritative. Individual sound adjustments
saved only in the old UI parameter dumps cannot be reliably reconstructed.
After verifying the sound, save the project again to capture a proper native
snapshot for subsequent launches. Never delete project files to test this fix.

VERIFICATION:
Static source checks passed; Unity and native iOS runtime not available here.
Do not resubmit a release to Apple until cold launch and project reload have
been checked on a physical iOS device / TestFlight.
